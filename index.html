    聽聽看狗狗會怎麼叫

    有沒有「每一種狗的叫聲」資料庫？沒有完整的。大部分品種的叫聲其實差不多，差別主要在體型：小狗聲音高、尖，大狗聲音低、厚。真正特別的只有少數幾種，例如巴仙吉不汪汪叫、會「約德爾」，哈士奇愛嚎叫和「講話」，米格魯會拉長音「長吠」。下面的錄音都來自維基共享資源（Wikimedia Commons），是真實錄到的狗叫聲，沒有任何合成。

    特別的叫聲這三種狗，叫聲真的不一樣

    想聽更多？

    Freesound（freesound.org）有很多網友上傳的狗叫錄音，搜尋 dog bark、dog howl 就找得到；用在課堂上請挑 CC0 或 CC BY 授權，並標示錄音者。帶活動時也可以請大家「學狗叫」：小狗怎麼叫？大狗怎麼叫？狗狗想出門會怎麼叫？

    ADOPT ME!領養代替購買

    台灣收容所裡有很多等家的狗狗，大部分是米克斯，也有台灣犬和被棄養的品種狗。品種只是外表，個性、健康和一輩子的照顧才是重點。想養狗，請先去收容所看看。

    養狗前先想 5 件事

    1. 狗狗大約活 12–16 年，我能照顧牠一輩子嗎？
    2. 家裡的空間、時間，夠牠每天散步、玩耍嗎？
    3. 看病、預防針、飼料、美容的費用準備好了嗎？
    4. 家人都同意嗎？有人對狗毛過敏嗎？
    5. 出國、住院的時候，誰來幫忙照顧？

    領養之後

    1. 植入晶片、辦寵物登記（法律規定）。
    2. 建議絕育，減少流浪狗，也對健康有幫助。
    3. 按時打預防針、吃心絲蟲藥、驅蟲。
    4. 出門牽繩、撿便便，當有禮貌的狗主人。
    5. 給牠時間：新家要 3 天放鬆、3 週熟悉、3 個月才真正變成家人。

    去哪裡領養？

    各縣市都有公立動物收容所，也有很多民間的送養活動。可以先上網看看等待領養的狗狗照片。

    給帶領者的活動說明

    怎麼帶（30–45 分鐘）

    1. 用投影或大電視開這個網頁。長輩建議「看照片猜」；小朋友可以玩「模糊照片」或「放大局部」。
    2. 先不給提示，問大家：「大狗還是小狗？什麼顏色？耳朵立起來還是垂下來？」
    3. 猜不到再按提示：體型 → 毛色 → 耳朵尾巴 → 原本的工作 → 老家 → 有名的事 → 名字。卡住時按「給三個選項」。
    4. 揭曉後，挑 1–2 個小知識講，再用「聊一聊」的題目請大家分享回憶。
    5. 最後一起看影片，或到「狗狗會怎麼叫」聽錄音、學狗叫。

    帶領小撇步

    1. 一次玩 6–8 隻就好，留時間聊天比答對重要。
    2. 說出小名也算對：狼狗、哈巴狗、斑點狗、土狗都可以。
    3. 失智症長輩可以直接用「給三個選項」，降低挫折感。
    4. 有長輩曾被狗咬或怕狗，先問一下，尊重不想參與的人。
    5. 結尾帶到「領養代替購買」，也可以聊聊家裡過世的狗狗，給予陪伴與傾聽。
